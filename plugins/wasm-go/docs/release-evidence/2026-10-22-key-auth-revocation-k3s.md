# Key Auth 1.0.3 令牌吊销回归

日期：2026-10-22。环境：默认 `modelfusion-dev` VM，K3S + Helm，`higress-system`。

## 修复

原实现拒绝 `consumers: []` 和规则 `allow: []`，导致最后一枚令牌吊销后的正常空配置无法加载。请求处理还将空列表当成未配置规则，在 `global_auth=false` 时放行。

1.0.3 接受明确的空消费者注册表和空规则，用独立标记区分“未匹配规则”和“明确拒绝所有调用方”，并支持 Higress 合并到顶层的规则配置。缺少配置或非数组类型仍报错，单个消费者的凭据列表仍必须非空。未匹配规则且关闭全局认证的请求保持公开。

平台 SDK 同步使用 1.0.3，并移除 `global_auth=false` 消费者注册表中的旧全局 `allow` 字段，使允许列表只属于具体认证规则；否则空全局列表会影响公共 API。修复保留无认证路由的 `configDisable=true`。平台同时修复冷缓存吊销及路由停用保存授权的错误。

平台投影同时修复“客户 AI 路由的消费者列表为空时禁用认证规则”的放行行为，保留启用的空允许列表；普通公共入口及无认证内部路由保持显式清理路径。

14 项现场对照均通过：旧令牌返回 403，无令牌返回 401；其他有效消费者仍存在时，空路由授权也返回 403。公共管理 API 和四个域名首页均返回 200。本测试用户最后一枚令牌已吊销；共享网关保留其他任务的有效消费者，全局注册表为空的情况由 Go/Wasm 回归覆盖。

鉴权对照使用非法音色：有效令牌到达 DashScope 返回 `InvalidParameter` 400；被吊销、未知或无授权的令牌应在网关返回 401/403。此检查不将上游 400 解释为语音生成成功。

1.0.2 是中间验证制品，未通过全部现场检查，最终使用 1.0.3。凭据、登录态、原始消费者配置、数据库连接串及上传令牌未写入本记录。
